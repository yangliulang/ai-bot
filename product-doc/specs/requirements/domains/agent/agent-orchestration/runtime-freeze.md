## 1. `orchestrationVersion`

- **每个** **发布级** **编排定义** **须** **携带** **单调可比较** **版本**（**整数/ semver** **由** **工程定** — **产品** **只** **要求** **可稽核**）。  
- **客户端/观测** **须** **能** **在** **`agent.orchestration.step`（或合并字段）** **读到** **该版本**（**FR-AO05**）。  
- **热修复** **不得** **静默** **改变** **用户已确认步骤** **的** **语义**；**若** **改变** → **新版本号** **+** **兼容策略** **（ADR/MR）**。

## 2. DAG 冻结

- **节点类型枚举**（**plan / tool / confirm / terminal** **等**）**与** **允许边** → **以实现仓库** **`Runtime`/Planner** **冻结** **为准**；**本篇** **不** **提前** **穷尽** **实现细则**。  
- **契约收口**：[`../../contract-closure.md`](../../../contract-closure.md) **脚注** **「§4 **`scenarioId`/矩阵解冻」** — **须在** **`routing-engine.md`** **`design/api`** **同窗** **更新**。

### 2.1 有向环 · 产品下限与实现分工

- **安全网（产品）**：**即使** **拓扑上** **存在** **有向环** **或** **Planner** **反复进入** **同类节点**，**同一 `executionId` 内** **编排步单调计数** **仍须** **受** [`execution-lifecycle.md`](execution-lifecycle.md) **§4 · `FR-AO06` 硬顶约束** — **达到上限** **须** **终止** **工具与外网 IO 扩张** **并** **可解释**（**`SC-AO-08`**）。
- **产品裁决（首版）**：**需求侧** **不** **单列** **「静态 DAG 必无环」** **之** **硬法条**；**以** **`FR-AO06`** **为** **必选** **安全网**。**是否** **对** **已承诺 `scenarioId`** **冻结** **无环有向图**、**或** **叠加** **环检测** — **由** **`design/runtime-architecture`** **与** **DAG MR** **收束**；**合并前** **须** **与** [`implementation-alignment.md`](implementation-alignment.md) **§6** **「DAG / `FR-AO06.2` / `runtime-freeze` §2.1」** **勾选** **同窗**。

### 2.2 产品侧关键依赖（交易写 · 示例性）

**非** **DAG 节点枚举** **亦非** **全库拓扑** — **仅** **锁** **「常见事故」** **之** **先后下限**；**与** **[`execution.md`](../../../Runtime/execution.md) §1**、[`trade-assistance.md`](../exchange-agent/trade-assistance.md)、[`confirmation-flow.md`](confirmation-flow.md) **对读**。**具体图** **实现 DAG MR** **冻结**。
