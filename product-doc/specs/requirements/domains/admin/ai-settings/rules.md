# AI Settings · 规则与约束

1. **Secret**：**仅** Secrets Manager / KMS **引用**；UI **轮换**走 **临时凭证** 或 **密钥服务** 托管流程；**日志与审计** **默认** **不得** 含 Key 全文（见 [`observability/overview.md`](../../../observability/overview.md)）。
2. **计费**：Token 计量与 **单价** **真源** 在 **`billing`** + **模块五**（**FR-MC502** 等）；本域 **只** 影响 **「连哪、用哪模型」**，**不** **改变** **扣费主体** **或** **费率键**。
3. **可用性**：切换默认模型 **须** **可回滚**（**配置版本** 或 **快照** **`design` 冻结**）；**Health** **须** **可挂钩** 告警（**SRE**）。
4. **合规**：**禁止** 向 **非授权** 角色展示 **Secret**；**导出** **若含** **连接元数据** **须** **水印 / 权限** **与** **模块八** **导出** **精神** **对齐**（**若** **本域** **提供** **导出** — **V1** **可** **不做** **全量导出**）。
5. **契约**：**OpenAPI 登记表** 未填前，控制台能力 **不对外承诺** — **`CC-P0-01`**。
