## 方向

- 仅在 **Coobit** 交易所场景落地，**不按多租户商户 SaaS** 交付。
- 对客形态 **本版** **仅** **Telegram** 会话渠道（见 [`domains/agent/telegram/overview.md`](domains/agent/telegram/overview.md) **§2.5 · 类型 A；总则 §2～§2.6**，[`README.md`](domains/agent/telegram/README.md) **索引**）；**App** **不**纳入本版（[`mobile-app.md`](domains/agent/telegram/mobile-app.md) 暂缓）。
- **触点分界**：**用户配额/消耗** **均在交易所站内** — **`/subaccount/billing` · `me/commerce`**（[`domains/web/agent-billing.md`](domains/web/agent-billing.md)、[`admin-console-web-billing-reconciliation` §0](domains/web/admin-console-web-billing-reconciliation.md)）；Telegram **Deeplink** **跳入站内**。**历史 `me/billing` OpenAPI** **见 CC-P0-03** — **本仓原型不实现**。
- **用户侧 Agent 计费 UX**：**`/subaccount/billing` · `me/commerce`** — **Capability 配额与消耗摘要**（**FR-B17～B20**、**FR-WEB07～11**）— [`commerce-model.md`](domains/admin/billing-management/commerce-model.md) **§5.3**、[`web-billing-reconciliation` §0](domains/web/admin-console-web-billing-reconciliation.md)。
- 用户 **开通 Exchange Agent（AI Trading Companion）** 须 **同时具备**：① **产品线绑定页完成保存且 §1.2 校验通过** **后的** **可归因链路**（含 Runtime/Telegram 映射；**不要求**用户 **登录或进入 Coobit 交易所主站** 完成 onboarding）；② **Agent 专用子账户** 处于 [`billing` §2](domains/admin/billing-management/overview.md) **就绪**口径（开立可走 **交易所**既有账户能力）；③ **子账户交易 API（Agent 绑定）**：用户在 **Agent 产品线绑定页**录入 **`agentSubAccountUid`**、**API Key + Secret** 并 **保存**，**`POST /api/v1/me/agent/bindings/trading-api`** **须通过** [`initialization-flow` §1.2 项 2](domains/agent/onboarding/initialization-flow.md) **下限校验**（[`FR-WEB06`](domains/web/agent-onboarding.md)、[`TradingApiBindRejectCode`](../openapi/components/onboarding-schemas.yaml)、[`design/api.md`](../design/api.md) **绑定探测矩阵**）**后** **托管绑定**并完成 **Telegram 与会话/实例映射**（[`domains/agent/onboarding/overview.md`](domains/agent/onboarding/overview.md) **§1.1**，[`domains/web/agent-onboarding.md`](domains/web/agent-onboarding.md)，[`domains/agent/exchange-agent/overview.md`](domains/agent/exchange-agent/overview.md) **FR-T01、FR-T02**）；**Telegram 首触**若无可用实例绑定 → **产品线 Deeplink** 引导至 **Agent** 绑定页。**全部** Agent 相关 **交易**经该子账户（**币币 / 杠杆 / 合约 / 理财** 等以所内产品为准）；**下单、撤单及策略所需交易所侧查询** **须**走 **子账户 scope** API，**禁止**默认使用 **主账户** Key。
- **计费与商业（2026-05-26）**：**对客**以 **订阅档位 + Capability（能力商品）+ 加购包** 为主叙事；**配额用尽即停**，**续用仅** **升级套餐或购买加购包**。**Agent 消耗 S5 仅轨 B 权益核销**；**Token** **为 Metering/观测维**，**非对客扣款单元**。**技术分层 SSOT**：[`domains/admin/billing-management/commerce-model.md`](domains/admin/billing-management/commerce-model.md) **v0.3.0**。**关单主链**：**轨 B + `me/commerce`**（**`contract-closure` §8**）。
- **同名 §7.4（防串号）**：[`domains/admin/billing-management/overview.md`](domains/admin/billing-management/overview.md) 指 **结算策略**（`BILLING_SETTLE_POLICY`）；[`domains/admin/management-console-v1-prd.md`](domains/admin/management-console-v1-prd.md) 指 **运营协查与计费流水导出** — 细节见 **各文档 §3**。
- **对上 Coobit 私有所内 HTTP（实现 vs 契约）**：**出站实现默认**由 **ChainUp 所内 `openapi-ai` 官方包**（Skill / CLI / MCP 等，**制品须 pin 版本**）承载；**能力边界、PATH、子账户 scope、504/对账与计费叙事**仍以 **[`design/api.md`](../design/api.md)** **矩阵**、**[`integrations/exchange/agent-coobit-api-allowlist.md`](integrations/exchange/agent-coobit-api-allowlist.md)**、**GitBook OpenAPI** 与 **域/Runtime** 为 **SSOT** — **详** **[`integrations/exchange/overview.md`](integrations/exchange/overview.md)**。**不**在本产品线侧 **长期并行维护** **与 `openapi-ai` 同源重复的** 「逐 PATH OpenAPI 调用规格 / 第二套工具 SSOT」；**类型 A、`FR-T0x`、`executionId`、计费、观测** **不变**。
- **统一交易语义与执行链（架构）**：**产品叙事** **以** **能力/意图** **为主**，**不** **将** **某所 REST 字段形态** **升格为** **跨产品线唯一真源**；**执行方向** **须** **Intent → Canonical → Gateway → Adapter → Coobit HTTP**（**同窗** **[`design/canonical-trading-model.md`](../design/canonical-trading-model.md)**、**[`ADR-004`](../design/adr/004-intent-centric-execution-and-canonical-trading-model.md)**、**[`trade-assistance` §2.6](domains/agent/exchange-agent/trade-assistance.md)**、**[`contract-closure` CC-P1-07](contract-closure.md#cc-p1-07)**）。**本 Git 规格仓** **只** **收** **需求与设计**；**Gateway/Adapter** **可执行实现** **与** **DoD B** **在** **所内工程仓库** **验收**。

## 非目标（当前版本）

- **多租户**商户 SaaS **经营后台**、**跨交易所**统一总后台对客产品与配套 RBAC；**不包含**租户间赠额、跨商户协查等对客能力。
- **单所例外**：Coobit **内部运营**用的配置与管理范围见 **`domains/admin/management-console-v1-prd.md`**，不等于对客「商户后台」产品。
- 实现细节（技术栈、库表、排期）：放在 **`specs/design/`**，不在本篇展开。
- **误解澄清**：**保留** **`specs/openapi/exchange/coobit-*.yaml` 与 `design/api` 矩阵** = **契约与收口 SSOT**（评审、白名单、对签、评测绑定），**≠** **要求本产品再手写一层 OpenAPI 调用「胶水」**；**胶水层** **由** **`openapi-ai` 官方宿主** **优先承担**（**同窗**上文 **方向** **条**）。
- **通用 Agent 运行时模型（V1 不产品化专卷）**：**Runtime IR**（中间表示 DAG）、**Worker Model**、**Distributed Execution**、**Nested Execution** — **本阶段** **不以** **独立需求卷** **交付**；**写路径因果序与风险闸** **见** [`Runtime/domain-model.md`](Runtime/domain-model.md)；**编排下限** [`runtime-freeze`](domains/agent/agent-orchestration/runtime-freeze.md) **§3**；**状态恢复** **见** [`Runtime/recovery.md`](Runtime/recovery.md)、[`persistence.md`](Runtime/persistence.md)、[`unknown-state.md`](Runtime/unknown-state.md)（**有** 条文，**无** 「Recovery 专卷」名）。
- **Exchange Agent · 暂不交付（现货高级组合写）**：**`trade.spot.oco` / `trade.spot.bracket`**（**OCO / bracket**，**同属「双挂/括号单」类组合语义**）**在本阶段不向用户放开写闭环**，**不须实现** **`call_exchange_write`** **链路**。**须** **`FR-T05`** **透明拒答**，或引导 **限价/条件单之分步入场离场** **或** **交易所主站** — **`trade-via-agent`**、[`telegram/overview`](domains/agent/telegram/overview.md) **§2.5.2** **同窗**。**编排键与 `skillId` 登记表可保留于 `routing-engine` / `trade-assistance`**，以备产品与矩阵解冻后 **`contract-closure` CC-P1-01 · MR-D** **同窗 MR** **回改本节解除**。**本条不覆盖永续合约条件单 **`fapi`** 路由 — **仍以 `routing-engine` 与矩阵为准**。
