# Phase 4 — 商业轨 B 宿主接线与用户 commerce 读路径（ChainUp）

> 产品 Agent 维护。backlog 对齐 `product-doc/product/roadmap.md` **横切 · 计费商业模型（2026-05-26～27）**、[`closure-completion-matrix`](../../product-doc/specs/requirements/closure-completion-matrix.md) **§3 OP-BILL**、[`closure-internal-sprint`](../../product-doc/specs/requirements/closure-internal-sprint.md) **MR-BILL-B1/B2** 与 **W4（可选）**。  
> **存量已实现**见 [`inventory.md`](../product/inventory.md) §2（本表 **不** 重复标 `planned`）。Phase-3 五项均已 **done**（见 [`phase-3.md`](phase-3.md)）。

## 阶段目标

1. 在 **`server/`** 落地 **consume-and-bill 轨 B**：**S2 额度门禁** + **S5 `ENTITLEMENT_DEBIT` 核销**（对照 `product-doc` OpenAPI **`internal/billing-entitlements`**），对齐 **OP-BILL** 所内 **黄→绿** 的宿主部分。
2. 提供用户侧 **`me/commerce`** 摘要与消耗流水读 API（**FR-B17 / FR-WEB08～09**），与 Deeplink **`?start=ab*`** 叙事同窗，**不**实现 **`me/billing` 轨 A**（**CC-P0-03 归档**）。
3. 产出 **staging 证据**（`executionId` + `billingTraceId` join），登记 [`closure-staging-evidence-log`](../../product-doc/specs/requirements/closure-staging-evidence-log.md) / **SC-B20～B21**；**不**宣称 **CC-P0 红项** 或 **Hosted 全关单**。

见 [`inventory.md`](../product/inventory.md) §5，并补充：

- **CC-P0-01 Hosted/tag**、**CC-P0-02 矩阵延期**、**CC-P0-03 Token 三线生产首填**、**CC-P0-04/05** — 运维/会签，**非**本阶段单 MR

- **PSP 买包支付到账**（**FR-B18** 到账前不得展示已生效）— design MR 另立项

- **单 MR 堆叠**：S2 + S5 + Gateway + Publish
